# Devlog skill

A reusable agent skill for maintaining concise, searchable engineering logs across projects.

## Included

- `SKILL.md` — skill instructions only.

This repository contains no personal notes, sample project logs, or user-specific configuration.

## Install

Copy this repository's `SKILL.md` into a skill directory named `devlog`, or follow your agent's instructions for installing skills from a GitHub repository. The skill is designed to work with a project log of your choice; it does not prescribe a storage path or require a specific tool.

Before using it, make sure the target project's own instructions describe its log structure and conventions.
